A new clock face for Nightscout Clock, now built and running on a Ulanzi TC001 with Dexcom Share. This page draws the TC001's 32 × 8 display pixel for pixel, with the firmware's own 3 × 5 digits, 5 × 5 trend arrows and default range colors. Readings below are made-up examples.

Pixel layout

The graph fills the left side, one column per 5‑minute Dexcom reading, newest on the right. The value sits next to it, and the arrow takes the same right-hand spot it uses on the Simple face. The bottom row under the value shows the minutes-since-reading dots the other faces already use.

Graph span setting

Status

Built from Nightscout Clock 1.3.5 and running on a TC001, reading Dexcom Share. The face is called Graph, value and arrow and has a Graph span setting of 1, 2 or 3 hours under Clock faces.

How it works

  • A ~40-line face that reuses the firmware's own graph, value and arrow drawing.
  • Each graph column averages the readings in its slice of the span, and never covers less than 5 minutes, so there are no gaps between Dexcom readings.
  • The settings page preview shows it too.

Trade-offs

  • With a 3-digit value the graph has 14 columns; a 2-digit value leaves 18.
  • The arrow takes 4 more columns than the built-in face's trend bar.
  • mmol/L values like 6.2 fit the same space.
Firmware

The code on GitHub

The graph-arrow-face branch of a fork of Nightscout Clock (LGPL-2.1). It is not in the official release yet: build it with PlatformIO and flash it over USB.

Open the branch https://github.com/vortecguy/nightscout-clock/tree/graph-arrow-face
Hardware

Ulanzi TC001 Smart Pixel Clock

The ESP32 pixel clock this runs on, about $42 on Amazon. Nightscout Clock replaces its stock firmware over USB; back up the original first.
